# Start here

This folder is your working copy of the plan for the Ojai Brush Guy tool. Claude keeps the master copy.

**Try the tool:** double-click "Open Brush Tool". It opens the latest saved version in your browser; the badge shows
its revision (quote it in your notes). A small "Brush tool demo" window runs it: close that window to stop it.

1. Open any file here and change whatever you like, or write ideas and requests in OWNER NOTES.md.
2. Save. Claude picks up your changes once you have stopped editing for about a minute
   (while Claude is working, or the next time a Claude session starts).
3. Claude reviews each change, writes down what it did and why, and updates the plan and the tool.
4. Your file is never overwritten while it has changes Claude has not reviewed yet.
5. After review Claude refreshes the file here with the merged version. If you had it open, reopen it.
6. If Claude disagrees or needs an answer, it explains why in the log and asks you. Your goals win.
7. The "Claude log" folder (it appears after the first review) shows what Claude did with every edit.
8. Claude rewrites "Claude log" and this file, so edits there are ignored.
9. New files you create here are not read. Put new ideas in OWNER NOTES.md.
10. The "agents" folder holds the instructions for Claude's independent checker. You can edit it too.
